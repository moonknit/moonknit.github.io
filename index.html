DeepResearch

2025.08 – 2026.06
Agent Engineering ReAct Context Compaction Planning Tool

오픈소스 OpenManus의 ReAct(Reasoning / Action / Observation) 기본 구조를 확장한 Deep Research Agent입니다. Web Search, 샌드박스 Code Execution, 계획 도구, 스킬을 조합해 길고 도구 의존적인 작업을 수행하도록 Observation 처리, 컨텍스트, 종료 제어를 다시 설계했습니다.

  • 장시간 에이전트는 컨텍스트 윈도우 한계보다 먼저 "컨텍스트 희석"으로 무너진다. 매 step마다 소형 LLM 한 번으로 원본 Observation 처리와 컨텍스트 압축을 함께 수행하고, 다음 step은 append-only 히스토리 대신 goal + state + plan으로 재시작합니다. 프리픽스 캐시 중심 대안은 프로토타입 후 산출물 품질 때문에 폐기했습니다.
  • 계획 도구는 에이전트의 뼈대가 된다. 최종 synthesis 턴을 보장하는 todo 진행으로, 요청의 일부만 답하고 끝나는 문제를 줄였습니다.
  • 종료는 분위기가 아니라 계약이다. terminate 전에 구조화된 목표와 completion check를 실행합니다. LLM은 분류하고, 코드가 결정하며, safety net이 나머지를 막아 불완전한 답변과 어긋난 종료 시점을 줄입니다.

위 데모가 "에이전트를 만드는 일"이라면, 이쪽은 이미 있는 코딩 에이전트를 어떻게 다룰지에 대한 일입니다. 회사 비공개 저장소의 프로젝트라 라이브 데모 대신 설계 인사이트를 정리했습니다.

specforge

2025.11 – 2026.08
AI-Assisted Development Cursor Agent Skills Spec as SSOT

Cursor 같은 범용 코딩 에이전트를 통제된 개발 시스템으로 만드는 하네스입니다. 프로젝트를 요구사항 정리 → 계획 → 실행 흐름으로 진행시키며, 에이전트 스킬과 커맨드로 구현했습니다. 에이전트를 만드는 것이 아니라, 이미 있는 에이전트를 어떻게 다룰지를 설계한 작업입니다.

  • 채팅 컨텍스트는 기억이 아니다. 저장소의 명세 문서가 기억이다. SRS를 단일 진실 공급원(SSOT)으로 삼고, 계획과 진행 상태를 파일에 둡니다. 새 세션이나 다른 에이전트도 프로젝트의 실제 현재 위치에서 이어서 작업합니다.
  • 자율성에는 경계가 필요하다. Task마다 구현 전 범위 게이트, 구현 후 diff-Task 점검을 거칩니다. 막힌 Task는 재시도하지 않고 에스컬레이션하고, 작은 변경은 가벼운 경로로 처리합니다.
  • 문서·코드·테스트는 어긋난다. 정기적으로 맞춰야 한다. drift-sweep 스킬이 코드와 테스트를 SRS에 맞추고 고아 코드를 정리하며, wiki 스킬이 에이전트가 읽는 프로젝트 지식을 동기화합니다.

재사용 가능한 스킬은 위의 skill-faro로 패키징해 Cursor와 Claude Code에서 공유합니다.
